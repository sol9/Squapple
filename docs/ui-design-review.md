# UI 시안 검토 — 2026-10-09

사용자가 제공한 `사각사과 UI 시안.html`의 M0~M9를 확인했다. 이 문서는 검토 의견이며 디자인·기능 확정이나 적용 승인을 뜻하지 않는다. 개발은 기존 모바일 출시 체크리스트 순서를 따른다. 전체 아이디에이션 시안은 해당 기능을 검토할 때 함께 확인한다.

## 유지하면 좋은 점

- 홈의 시작 버튼과 플레이의 시간·점수가 명확하다. 회색 바탕과 단순한 숫자 표현이 퍼즐에 집중하기 좋다.
- 첫 안내의 `3 + 7 = 10` 예시가 규칙을 짧게 전달한다.
- 결과에서 새 판과 같은 판을 구분하고, 같은 판을 연습으로 명시한 점이 기존 방향과 맞는다.
- 나가기 확인과 앱 복귀 화면을 구분해 실수 종료와 갑작스러운 시간 재개를 줄일 수 있다.

## 적용 전에 확인할 점

1. **도움 표시:** 기존 계획은 기본 모드 하나이며 선택 합 표시가 포함돼 있다. 시안처럼 클래식/도움 표시를 나누면 기록 기준·설정·안내 범위가 늘어난다. 이번 개발에서는 기존 선택 합 표시를 유지하고 모드 분리는 결정하지 않는다.
2. **보드 크기:** 393px 시안의 약 40px 사과는 작은 휴대폰에서 더 작아진다. 8×13을 유지하되 보드 높이와 드래그 정확도를 먼저 검증하고 실제 기기에서 판단한다.
3. **손가락 가림:** 상단 선택 합은 도움이 된다. 선택 테두리와 합이 손가락 밖에서도 읽히는지 드래그를 붙여 확인한다. 시안의 손가락 모양은 설명용이며 게임 요소가 아니다.
4. **복귀:** 숫자를 가린 채 명시적으로 재개하는 방향은 적절하다. 3초 카운트다운은 5단계의 중단·복귀 정책을 구현할 때 함께 결정한다.
5. **마지막 10초:** 시간 글자·진행 막대의 색 변화부터 확인하고, 화면 전체 테두리 강조의 필요성은 실제 플레이 후 판단한다.
6. **첫 안내:** M0의 첫 안내→홈과 M2의 ‘시작’ 버튼이 실제로 어디로 이동하는지는 적용 시점에 맞춰 일치시킨다.
7. **설정·광고:** 실제 동의 SDK·정책 URL·문의 주소가 정해졌을 때 해당 항목을 연결한다. 시안의 광고 노출 문구는 광고 빈도의 확정값으로 취급하지 않는다.

## 현재 개발 범위

4단계 첫 작업은 uGUI로 홈→플레이→결과, 일시정지, 보드 드래그·합 표시·선택 취소, 화면 크기·Safe Area 대응을 연결하는 기능 프로토타입이다. 시안의 외형, 도움 모드, 광고, 로컬 기록 확장은 이번 작업 범위에 넣지 않는다.
