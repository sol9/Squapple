# 로컬 기록과 같은 판 연습

- 작업일: 2026-10-09
- 대상: 6단계 기본 솔로, 로그인·서버 없이 기기 안에 저장

## 플레이 흐름

홈은 현재 기본 규칙의 최고 기록과 ‘지난 판 연습’을 표시한다. 완료한 판이 없으면 연습 버튼은 비활성화한다. 결과는 이번 점수와 최고 기록을 보여주며 ‘새 판’, ‘같은 판 연습’, ‘홈으로’를 제공한다.

일반 판이 시간 종료·모두 제거·조합 없음으로 끝나면 결과를 먼저 저장하고 결과 화면을 연다. 더 높은 점수만 최고 기록을 바꾼다. 그만하기·새 판으로 중간에 버린 판과 강제 종료된 진행 중 판은 기록하지 않는다.

같은 판 연습은 제거되기 전 숫자 배열과 당시 보드 크기·시간을 사용한다. 씨드로 재생성하지 않으므로 생성 알고리즘을 바꿔도 저장한 판의 숫자는 달라지지 않는다. 점수와 시간은 새로 시작하며 연습 표시를 계속 보여준다. 연습이 끝나면 결과와 마지막 판을 저장하지만 일반 최고 기록에는 반영하지 않는다. ‘새 판’은 현재 개발 설정의 기본 규칙으로 돌아간다.

마지막 완료 판 하나만 보관한다. 기록 목록·랭킹·리플레이 행동 기록은 첫 구현에 추가하지 않는다. 앱을 다시 켰을 때 홈에서 이 판을 연습할 수 있다. 진행 중 판을 이어 하는 기능은 없다.

## 저장 형식과 업데이트

| 항목 | 방식 |
| --- | --- |
| 저장소 | PlayerPrefs의 `Squapple.Progress`, JSON 한 개 |
| 데이터 형식 버전 | `version = 1` |
| 최고 기록 구분 | 규칙 버전·가로·세로·제한 시간의 조합 |
| 최고 기록 값 | 같은 조건에서 완료한 일반 판의 최대 점수 |
| 마지막 판 | 조건, 원본 숫자 배열, 점수, 종료 이유, 연습 여부 |
| 소리·진동 | 기존 `Squapple.Settings.Sound` / `Squapple.Settings.Vibration` 키 유지 |
| 안내 확인 | 현재 홈 안내는 항상 표시한다. 별도 안내 화면의 확인 여부 저장은 그 화면을 만들 때 연결한다 |

현재 버전은 첫 기록 형식이다. 이전 빌드에는 이 키가 없으므로 빈 기록으로 시작하고 기존 소리·진동 설정은 보존한다. 같은 형식의 앱 업데이트는 기존 데이터를 읽는다. 규칙 버전이 다르면 최고 기록을 섞지 않고 현재 규칙으로 해석할 수 없는 마지막 판은 연습에 사용하지 않는다.

이 앱보다 높은 저장 형식 버전은 덮어쓰지 않는다. 해당 버전에서 기록을 저장할 수 없다는 결과 안내를 표시하며 기본 플레이는 허용한다. 손상된 JSON은 빈 기록으로 시작하고, 읽을 수 있는 형식 안의 유효하지 않은 기록·보드만 제외한다. 정상 완료 시 새 형식의 유효한 데이터를 저장한다.

저장은 판마다 한 번이며 결과 화면을 띄우기 전에 `PlayerPrefs.Save()`를 호출한다. 프레임마다 저장하지 않는다. PlayerPrefs는 기기 안의 간단한 데이터 저장 수단이므로 앱 삭제 후 복원이나 다른 기기 동기화를 보장하지 않는다. [Unity PlayerPrefs](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/PlayerPrefs.html), [Save](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/PlayerPrefs.Save.html), [JsonUtility](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/JsonUtility.FromJson.html).

## 검증과 실기기 확인

자동 테스트는 실제 PlayerPrefs 읽기·쓰기를 사용하고 끝나면 원래 데이터를 복원한다. 테스트 데이터를 개발자의 실제 기록과 섞지 않는다. 프리팹의 결과 저장·연습 버튼·화면 파괴 후 재생성·서로 다른 보드 크기 전환도 검증한다.

Unity CLI/Pipeline 컴파일 오류 0개, EditMode **86/86**, PlayMode **15/15 통과**. 393×852의 홈·일반 결과, 320×568의 홈·연습 결과 배치를 확인했다. 시각 검증에 사용한 임시 기록은 원래 데이터로 복원했다. 모바일 빌드·설치는 이번 작업에서 실행하지 않았다.

에디터에서 저장 객체와 화면을 다시 만든 검사는 OS 프로세스 재실행이나 모바일 업데이트 설치와 다르다. 다음 빌드부터 아래 항목을 실기기에서 확인한다.

1. 일반 판 완료 → 홈 최고 기록·결과 점수 확인 → 앱 강제 종료·재실행 → 기록 유지 확인.
2. 홈 ‘지난 판 연습’ → 원래 숫자·시간 확인 → 더 높은 연습 점수로 완료 → 일반 최고 기록 유지 확인.
3. 판 중간에 종료 → 재실행 시 홈으로 시작하고 마지막 완료 판만 유지되는지 확인.
4. 소리·진동 설정 변경 → 재실행·새 빌드 덮어 설치 → 설정·기록 유지 확인.
5. 오프라인으로 위 흐름을 반복하고 Android·iOS 양쪽에서 확인.

광고는 아직 연결하지 않았다. 7단계에서는 저장과 결과 확인을 마친 뒤 다음 판 진입에 광고를 붙인다.
